# Lead Tracker Chrome Extension

A lightweight Chrome Extension designed to quickly save, store, and manage web links directly in your browser using local storage.

---

## Features

- **Save Input URL:** Type or paste any link into the input field and save it.
- **Save Active Tab:** Automatically captures and saves the URL of your currently active browser tab with one click.
- **Save on Enter Key:** Pressing `Enter` in the input field instantly saves the link.
- **Persistent Storage:** Uses `localStorage` so your saved links persist even after closing the browser.
- **Itemized Deletion:** Hover over any link to reveal options and delete individual entries dynamically.
- **Clear All:** Instantly clear all stored links with a single click.
